# 无边春 · 绘画练习画室

「谁言一点红，解寄无边春。」——苏轼《书鄢陵王主簿所画折枝二首》

一个面向初学者的中文绘画练习网站。在原油画调色项目基础上，增加分步调色、素描与油画互动，以及每日纸上练习。

## 本地运行

需要 Node.js 20.9 或更新版本。

```bash
npm ci
npm run dev
```

打开 http://localhost:3000 。生产预览：

```bash
npm run build
npm run start
```

验证：

```bash
npm run typecheck
npm test
```

## 练习方式

- **我的画室**：12 分钟练习建议（看明暗、调色、纸上排线），手动记录当日实际完成情况。
- **调色实验室**：明暗、黄蓝调绿、降低彩度、自然土色四节课，共 16 个模型内可达到的目标。默认有限色板，可展开全部示意色，支持搜索、品牌和色系过滤。
- **自由调色**：选择任意目标色，调整颜料份量，比较明度、彩度与色相。支持撤销、试调提示、参考配方和最近 20 次配方笔记。
- **素描基础**：五节练习包含空间与透视、球体光影、排线、观察比例和轮廓负形。空间实验室支持正方体、长方体、圆柱、斜切圆柱、圆锥、六棱柱和组合体，使用三维透视投影，可调转角、俯视、形体比例、切角与结构辅助线。比例与负形任务提供具体纠偏；每课附纸面任务与自检。排线练习纸支持鼠标、触笔和手指。
- **油画基础**：三节课分别练习色彩环境对比、明暗归纳和边缘控制。名画支持原色、灰度、三阶、五阶观察，三阶明暗分界可调；硬边、软边和局部消失边分别演示。完成知识自检后，可自行记录实体练习。
- **名画观察**：60 幅作品，每幅附具体观察任务，支持画家、五类题材、六类学习目标筛选，以及仅看新增馆藏。可从名画或本地图片提取主要颜色，切换黑白观察，直接把颜色带入调色台。
- **配色探索**：调整颜色面积占比、比较黑白层次、查看参考色接近的名画。

所有学习记录保存在当前浏览器的 localStorage；不含账号、云同步或后台 AI 服务。上传参考图片仅在浏览器中读取。自由绘画纸只保留当前页面内的笔迹。

## 调色模型与教学边界

混色使用 [Spectral.js](https://github.com/rvanwijnen/spectral.js) 的 Kubelka–Munk 近似模型，替代原来的 Lab 加权平均。输入仍是 RGB 示意色，颜料品牌色值并非实测反射光谱；比例是屏幕训练的份量，不保证等同真实颜料用量。真实材料的着色力、透明性、底色和厚度都会改变结果，应以实物试色校正。

练习相似度由 CIE76 色差映射计算，用于本网站内部比较，不代表人的绘画能力或艺术质量。自由目标可能超出所选色板范围，参考配方为有限搜索结果。查看配方后会标记为参考练习；独立检验达到 90 分时点亮该基础课。

光影和透视属于基础概念示意，不是精确光学渲染。素描课程完成由学习者自评。美术观察文案为明确的规则提示，不冒充模型生成点评或客观美学评分。

## 技术与数据

Next.js App Router、React、TypeScript、Tailwind CSS。保留原仓库的 30 幅名画，新增 30 幅芝加哥艺术博物馆馆藏，新增图像逐幅核验 API 的公共领域标记，依馆方开放政策使用 CC0 图像。新增来源、媒材、授权与文件哈希见 `public/paintings/aic-sources.json`；该清单不覆盖原仓库图像。主要页面都可依靠本地资源运行；可选 Wikimedia 图片代理只允许指定 HTTPS 图片来源，并限制重定向、时长和体积。

- `atelier-mix-progress-v1`：基础调色课程完成情况与最近配方。
- `atelier-sketch-progress-v1`：五节素描纸上练习自评，兼容此前三节课的记录。
- `atelier-oil-progress-v1`：三节油画实体练习记录。
- `atelier-daily-v1`：按本地日期记录的每日三步练习。
